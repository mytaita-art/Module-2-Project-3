# Lexicon — тренажёр словарного запаса

Веб-приложение для изучения иностранных слов методом интервального повторения (spaced repetition).
Работает полностью в браузере, без сервера и без API — все данные хранятся в `localStorage`.
Готово для публикации на GitHub Pages.

## Что делает приложение

- **Колоды слов** — создаёшь набор (например, "Испанский A1") и добавляешь пары слово/перевод + необязательный пример использования.
- **Тренировка карточками** — переворачиваемая 3D-карточка: сначала видишь слово, кликом переворачиваешь и видишь перевод и пример.
- **Алгоритм SM-2 (spaced repetition)** — после каждой карточки нужно оценить, как хорошо ты её вспомнил: «Забыл», «Сложно», «Хорошо», «Легко». В зависимости от оценки система сама рассчитывает, когда показать это слово снова (через минуты, дни или недели) — это и есть интервальное повторение, доказанно самый эффективный способ запоминания.
- **Дашборд с графиками** — линейный график активности за 14 дней и кольцевая диаграмма распределения слов по стадиям (новые / изучаются / освоены). Построено на Chart.js.
- **Прогресс-бары** — по каждой колоде видно процент освоенных слов, плюс общий streak (счётчик дней подряд с тренировками).
- **Озвучка (Text-to-Speech)** — на каждой стороне карточки есть кнопка-динамик, которая проговаривает слово через встроенный в браузер синтезатор речи (Web Speech API). Для каждой колоды при создании выбирается язык произношения (12 языков на выбор: английский UK/US, испанский, французский, немецкий, итальянский, португальский, японский, корейский, китайский, русский, турецкий). Можно включить автоозвучку — слово проговаривается само при открытии карточки — и настроить скорость речи в настройках.
- **Импорт/экспорт** — весь прогресс можно выгрузить в JSON-файл (кнопка «Экспорт») и загрузить обратно на другом устройстве (кнопка «Импорт»).
- Демо-колода из 10 английских слов подгружается автоматически при первом запуске, чтобы сразу увидеть, как всё работает.

## Технологии

- Чистый HTML / CSS / JavaScript (без фреймворков и сборщиков)
- [Chart.js](https://www.chartjs.org/) — для графиков (подключается через CDN)
- Web Speech API (`SpeechSynthesisUtterance`) — озвучка, встроена в браузер
- `localStorage` — хранение данных без бэкенда

## Структура файлов

```
lexicon/
├── index.html   — разметка всех экранов (дашборд, колоды, тренировка, настройки)
├── style.css    — тёплая фисташковая палитра, все иконки — SVG (без эмодзи)
└── app.js       — вся логика: SM-2, графики, озвучка, работа с localStorage
```

## Как запустить локально

Просто открой `index.html` в браузере — двойным кликом. Работает без сервера,
но если браузер блокирует что-то через `file://`, можно поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub и залей туда все 3 файла (`index.html`, `style.css`, `app.js`).
2. Зайди в **Settings → Pages**.
3. В разделе **Source** выбери ветку `main` и папку `/ (root)`.
4. Через минуту-две сайт будет доступен по адресу:
   `https://твой-логин.github.io/имя-репозитория/`

## Про озвучку — важные нюансы

- Голоса предоставляет сам браузер/операционная система. В Chrome на Windows/Mac голосов
  много и они звучат хорошо; в некоторых мобильных браузерах выбор голосов беднее.
- Если для выбранного языка колоды нет установленного голоса, браузер использует ближайший
  доступный (например, для `en-GB` может звучать `en-US`, если британского голоса нет).
- Функция работает полностью оффлайн-совместимо в большинстве браузеров (кроме совсем старых),
  дополнительных ключей API не требуется.
